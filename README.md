## Sala de reuniones - The Optimal Partner

- clonar repositorio

- [ ] git clone https://github.com/marcoacevedogarridodev/Sala_de_Reuniones_Dev.git

- crear ambiente virtual

- [ ] python3 -m venv env

- activar ambiente virtual

- [ ] source env/bin/activate Windows env\Scripts\activate

- instalar dependencias

- [ ] pip install djangorestframework
- [ ] pip install django-cors-headers

- migrar base de datos

- [ ] python manage.py makemigrations
- [ ] python manage.py migrate

- levantar backend DjangoRestFramework

- [ ] python manage.py runserver

- dentro de carpeta server correr test

- [ ] python -m unittest test.py

- levantar frontend React

- [ ] npm start
